# 01. Детерминизм против server-authority

**Дата:** 2026-08-18
**Статус:** accepted

## Контекст

Void Dominion — real-time MMO 4X-стратегия с асинхронным геймплеем (игрок выдаёт
приказы, которые исполняются часами реального времени; мир 24/7). Два требования
конфликтуют:

1. **Детерминизм.** Симуляция должна быть чистой функцией: одинаковые
   `(state, action, context)` → одинаковый результат. Это нужно для реплея,
   анти-чита (server-authority проверяет состояние), отладки desync и
   воспроизводимости багов.
2. **Server-authority.** Клиент отправляет намерение, не состояние. Валидация,
   авторизация, идемпотентность — на сервере. Ядро предполагает, что действие уже
   прошло гейты.

**Альтернативы:**

- **A.** Ядро — чистая функция, AI/случайность — на сервере. Сервер генерирует
  действия и подаёт через `applyAction`. Время — через `Context.now`, RNG — seeded.
- **B.** Ядро содержит AI и `Date.now()` — «умное» ядро, которое само принимает
  решения. Проще для прототипа, но ломает детерминизм и реплей.
- **C.** Два ядра: детерминированное для симуляции, отдельное для AI. Двойная
  логика, риск расхождения.

## Решение

**Альтернатива A.** `shared-core` — чистая функция:

- `applyAction(state, action, ctx)` и `advanceTo(state, ctx)` — детерминированные,
  без `Math.random()` и `Date.now()` (ESLint enforced в `shared-core/src/**`).
- Время приходит через `Context.now` (сервер передаёт).
- RNG — seeded (`Rng`), locked golden-тестом (`rng.test.ts`).
- AI (боты, steward, substitute) — на сервере (`prototype/src/ai.ts`,
  `packages/server/src/standingOrderDriver.ts`), генерирует действия и подаёт через
  `applyAction`. Ядро «не знает», что действие пришло от AI, а не от человека.

## Последствия

**Плюсы:**
- Реплей работает: один seed + последовательность действий = тот же результат.
- Анти-чит: сервер может пересчитать состояние и сравнить с клиентским.
- Отладка desync: детерминированный прогон воспроизводим.
- Тестирование: `pnpm run check` + property-тесты на чистых функциях.

**Цена:**
- AI не может быть «внутри» ядра — нужен внешний оркестратор (сервер).
- Сервер должен тикать AI для ботов (clockDriver, standingOrderDriver).
- RNG-алгоритм заморожен golden-тестом — смена инвалидирует реплеи существующих
  матчей.

**Совместимость:** server-authority (инвариант #5), fail-secure (инвариант #4),
модульная шина (инвариант #3 — AI-действия идут через ту же шину, что и
игроковые).
