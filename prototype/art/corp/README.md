# Здания базы корпорации: уровни I–III

Нарезка листов владельца из [art/corporations](../../../art/corporations/README.md): на листе
три уровня здания слева направо, здесь — файл на уровень. Режет
[cut-corp-art.py](../../../scripts/cut-corp-art.py) (numpy и Pillow), из корня репозитория:

    python3 scripts/cut-corp-art.py

Скрипт перезаписывает все файлы этой папки вместе с `manifest.json`.

- Граница уровней идёт по шву наименьшей прозрачности: стрела крана, протянутая к соседу,
  остаётся со своим уровнем.
- Уровни I и III совмещены с уровнем II по полосе платформы. Все три лежат на общем холсте,
  низ холста — фронт платформы, поэтому повышение уровня не сдвигает здание на панораме.
- Ширина холста — около двух участков панорамы: штаб 560, центр снабжения 460,
  инженерный комплекс 500 пикселей. WebP, quality 82, method 6.

`manifest.json` хранит размер холста и рамку нарисованного на каждом уровне в долях холста
(x0, y0, x1, y1). По рамке хаб строит зону нажатия.

Хаб рисует базу в стиле, который применил глава корпорации ([corpArt.ts](../../src/corpArt.ts));
имперская готика и хайтек продаются в магазине (CORP-14).
