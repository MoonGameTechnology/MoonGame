> При заметном сдвиге строку переписывают, а не дописывают рядом. Подробности —

**Гейт:** ✅ зелёный · `pnpm run check` (lint + typecheck + test + docs-check) ·
актуальный счётчик тестов — в шапке [`state.md`](state.md) (единственный дом этого числа).

## Коротко

- **Играбельны две игры на одном ядре.** Galactic War (основная стратегия) — соло с
  ботами и по сети, уровень альфы. Sector Zero (PvE-кампания) — шесть глав, архив под
  Яндекс Игры собирается и проходит робота площадки (`smoke:yandex`).
- **Игроки получают клиент из `prototype/`.** Его раздают образ сервера
  (`proto-server.mjs`, собран из `prototype/netserver.ts`), сайт на Cloudflare, GitHub
  Pages и оба APK. Новый клиент `packages/client` игрокам пока не отдаётся.
- **Внешних игроков, публикации в магазинах и продуктовых метрик пока нет.** Что держит
  выход — [`release-path.md`](release-path.md).

## Где это доступно

- **VPS владельца** — `https://77-221-140-87.sslip.io/`: сервер партий и игра, HTTPS через
  Caddy, автодеплой с `main`, закрытый мониторинг
  ([отчёт о запуске](reviews/2026-10-18-obs-vps-bootstrap.md)).
- **Сайт на Cloudflare** — воркер из `wrangler.jsonc`: только страницы клиента, адрес
  сервера партий вшит на сборке (`GAME_SERVER`).
- **GitHub Pages** — `https://moongametechnology.github.io/MoonGame/`, соло-сборка,
  выкладывается с `main` (`pages.yml`).
- **Android** — два APK из `android.yml`: dev (`alpha`) и player (`player`), оба
  обновляются сами и стартуют с адресом VPS. Отдельный release-воркфлоу под RuStore
  (`rustore.yml`) готов, публикации нет.

## CI

- `ci.yml` — гейт (`pnpm run check`) и OSV-Scanner против сервисного Postgres на каждый
  push в рабочую ветку, PR и очередь; required check `check`, `main` защищён.
- `security.yml` — Semgrep, CodeQL, Trivy, OSV, Gitleaks, TruffleHog, zizmor; оттриаженные
  сканеры блокирующие, плюс еженедельный прогон по `main`.
- `image.yml` — образ сервера: сборка, блокирующий Trivy, GHCR, подпись cosign.
- `android.yml`, `rustore.yml`, `rustore-smoke.yml` — APK и проверки под RuStore.
- `pages.yml` — GitHub Pages. `automerge.yml` — готовые PR сами встают в очередь.

## Главные пробелы

1. **Нет живых внешних игроков и цифр удержания.** Порядок первого сетевого теста —
   PTM-2.2 🔶 в [`playtest-telemetry-roadmap.md`](playtest-telemetry-roadmap.md).
2. **Выход держат решения владельца, а не код:** название, подача Sector Zero в Яндекс
   Игры, оператор персональных данных, хранилище бэкапов вне VPS. Список с порядком —
   [`release-path.md`](release-path.md).
3. **Баланс основной игры не сведён** (см. этап 6).
4. **Push не доходит до игроков** (см. этап 5).
5. **Два клиента.** Игроки получают `prototype/`, а `packages/client` догоняет его
   медленно (см. этап 4).
6. **Продуктовой аналитики нет:** воронки и D1/D7 не считаются (M6 ⏳, OBS-2.1/2.2 и OBS-3 🔒).
   Телеметрия плейтестов есть (PTM-1/PTM-2).
7. **Эксплуатация не доказана на длинной дистанции:** нет прогона 24–72 ч, алертов и
   бэкапов вне машины (см. этап 7).
8. **Отложено сознательно:** OIDC, несколько процессов сервера, метаигра.
