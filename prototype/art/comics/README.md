# Комиксы глав Sector Zero

| Момент | Когда показывается |
| --- | --- |
| `intro` | Перед первым запуском главы. |
| `outro` | После первой победы, поверх итогов; у обучения — после успешной симуляции. |
| `task` | После ключевой задачи: глава I — спасение Учёного, глава IV — `chain.contact`. |
| `echo` | Глава I: после спасения Учёного живой корабль прибыл к ещё враждебной Эхо. |
| `echo-record` | Альтернативная архивная версия, если Эхо уже освобождена. |

Каждый момент показывается один раз на профиль (`SectorZeroProgress.comicsSeen`). Обе версии Эхо используют одну отметку `pve-1:echo`. Отметка пишется после закрытия страницы. Заявки сериализуются в `comicQueue.ts`: выполненная задача не теряется, если в том же кадре наступила победа. Пока очередь занята, симуляция остановлена; после чтения сохраняется прежняя скорость.

Escape/«назад» закрывают страницу сразу. Кнопки «Дальше» и «Пропустить» появляются через пять секунд (`COMIC_HOLD_MS`); до этого нажатие на картинку не листает её. При ошибке загрузки остаются внешние подписи, а страница без подписей пропускается.

## Файлы и формат

- Одна картинка — целая портретная страница комикса, вписанная в экран без обрезки. Текущие страницы — 1086×1448 (3:4), реплики нарисованы внутри.
- PNG-исходники, каталог, условия показа будущих глав и раскадровки: [art/comics/sector-zero](../../../art/comics/sector-zero/README.md).
- Игровые копии: WebP, качество 92, исходное разрешение; размер зависит от детализации и читаемого текста.
- Путь: `<глава>/<момент>-<номер>.webp`. Для английского варианта — `<момент>-en-<номер>.webp`. Только латиница, цифры и дефис.
- Сейчас подключены 14 русских страниц обучения и глав I–IV, плюс английское учебное вступление. У V–VI ещё нет игровых карт; их исходники в runtime не импортируются.

## Подключение и язык

Импортируйте файл в `prototype/src/comicArt.ts`, добавьте страницу в `CHAPTER_COMICS`. Для `task` нужен существующий id задачи или шага цепочки в `COMIC_TASK_TRIGGERS`. Если есть отдельная английская картинка, укажите `imageEn`: проигрыватель выберет её при `LOCALE === 'en'`, иначе покажет `image`. Внешние подписи, если нужны, задаются ключами `captions` с переводами в `localization/ru.ts` и `en.ts`.

```ts
 'training-1': {
   intro: [{ image: training1Intro1, imageEn: training1IntroEn1 }],
   outro: [{ image: training1Outro1 }],
 },
```

`pnpm run check` сверяет реальные главы, существование триггеров, переводы внешних подписей, файлы и импорты. В архиве площадки изображения вынесены в `assets/` и загружаются при показе; следующая страница подгружается заранее. В однофайловых сборках картинки вшиваются в HTML.
