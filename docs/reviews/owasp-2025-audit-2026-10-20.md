# OWASP Top 10:2025 — проверка ввода и границ доверия, 2026-10-20

Проверенная база: `a43003f5fce8` в `main`. Область: исполняемый веб-клиент
`prototype/`, общий протокол и ядро, оба серверных входа, HTTP/WebSocket,
админский клиент, Compose/Caddy, подписанная доставка, журналы и lock-файлы.
Классификация: [официальный OWASP Top 10:2025](https://top10.owasp.org/2025/0x00_2025-Introduction/).
Проверка исходников и локальные негативные сценарии дополнены чтением агрегированной
конфигурации действующего сервера. Атаки на игровые аккаунты/матчи на проде не выполнялись.
Это ограниченный аудит указанных поверхностей, а не гарантия отсутствия всех уязвимостей.

## Обновление паролей

Профиль выбран по [официальной OWASP Password Storage Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html#scrypt), прочитанной 2026-10-20. Старые хеши остаются проверяемыми, но их нельзя усилить офлайн без знания пароля: upgrade происходит при следующем правильном входе. Замена хеша намеренно отзывает прежние сессии, join-токены и ссылки сброса; текущий вход получает токен для нового хеша. Более сильный хеш не понижается. Неактивный аккаунт сохраняет прежний профиль до входа или смены пароля.

## Проверки и ограничения

Основной gate: `VITEST_MAX_WORKERS=2 pnpm run check`; сборка: `pnpm run prototype`. Дополнительно запускаются digest-pinned Semgrep с наборами CI и OSV по обоим lock-файлам, негативный TLS child-process тест, WebSocket/socket race тесты и release-image smoke с read-only FS.

Semgrep с digest-пином CI: 232 правила, 2 425 файлов, 0 находок. Получено 11 предупреждений `PartialParsing` на неизменённых файлах (современный TypeScript в тестах/экспортах и шаблон `prototype/build.mjs`); это ограничение охвата, не успешная проверка каждой строки. TypeScript и сборка этих путей проверяются отдельными командами, но не заменяют семантический анализ безопасности.

Gitleaks с digest-пином CI проверил снимок только отслеживаемых исходников и намеренных новых файлов (без node_modules/локальных build-артефактов): 0 утечек. Повторный точечный Semgrep охватывает дополнительно изменённые обработчики журналирования.

Изолированный замер KDF (три прогона каждого профиля): старый p1 — хеширование 86–94 мс и проверка 82–92 мс; p3 — хеширование 215–239 мс и проверка 221–232 мс. Максимальный RSS измеряемого процесса в обоих случаях — 92 MiB. Это не нагрузочный тест всего игрового сервера.

Для каждой исправленной границы добавлены регрессионные сценарии; конкретные итоговые
команды и результаты приведены в описании PR. Враждебные значения используются только
в тестах. Никакие реальные пользовательские секреты, тела запросов и персональные
данные в этот отчёт не включены.

Остаются организационные/инфраструктурные работы: независимые off-host бэкапы и доставка
alerts/SIEM, подтверждение SSH/firewall и recovery operator workflow, ручной разбор
контейнерных CVE и бизнес-правил против мультиаккаунтов. На проверенном хосте
`BACKUP_POLICY=deferred-playtest`: этот аудит не объявляет публичный релиз разрешённым.
