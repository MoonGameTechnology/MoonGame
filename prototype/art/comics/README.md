# Комиксы глав Sector Zero — куда класть арт

Решение владельца 2026-09-24: у главы может быть короткий комикс в двух местах.

| Момент | Когда показывается |
| --- | --- |
| `intro` | перед **первым** забегом главы («Новый забег» или «Сыграть главу снова») |
| `outro` | после **первой победы** в главе, поверх экрана итогов |

Каждый комикс показывается **один раз на профиль**. Отметка «показан» хранится в профиле
и переезжает с ним через облако. Игрок всегда может выйти: «Пропустить», «назад» и Esc.
Пока арта нет, комикс не показывается и игра идёт как раньше.

## Формат панели

- **Одна картинка — одна панель**, на экране по одной. Панель вписывается в экран целиком
  и на ПК, и на телефоне.
- **Размер 1600×1200 (4:3).** Главное держите ближе к центру: на телефоне панель маленькая.
- **WebP**, до ~250 КБ на панель (качество около 80). PNG или JPG тоже можно принести —
  их переведут в WebP.
- **3–6 панелей** на момент.
- **Без текста на картинке.** Реплики и подписи идут текстом под панелью из локализации:
  так работает английская версия, а текст остаётся чётким на любом экране. Если текст всё
  же нарисован, нужна отдельная картинка на каждый язык — сейчас это не поддержано.

## Имена файлов

Путь `<глава>/<момент>-<номер>.webp`, только латиница, цифры и дефис (требование площадки
1.22 к именам в архиве):

```text
prototype/art/comics/pve-1/intro-1.webp
prototype/art/comics/pve-1/intro-2.webp
prototype/art/comics/pve-1/outro-1.webp
```

Глава — id карты главы: `pve-1` — глава I, `pve-2` — глава II.

## Подключение

1. Импорт картинки в `prototype/src/comicArt.ts` и панель в `CHAPTER_COMICS` по порядку.
2. Подписи — ключи `sector-zero.comic.<глава>.<момент>.<номер>` в `localization/ru.ts` и
   `localization/en.ts`.
3. `pnpm run check`: сторож `prototype/src/comicArt.test.ts` сверит папку, реестр и
   переводы. Файл, который лежит, но не подключён, чужая глава и подпись без перевода
   роняют гейт.

```ts
import pve1Intro1 from '../art/comics/pve-1/intro-1.webp';

export const CHAPTER_COMICS: ComicRegistry = {
  'pve-1': {
    intro: [{ image: pve1Intro1, captions: ['sector-zero.comic.pve-1.intro.1'] }],
  },
};
```

В архиве площадки картинки лежат отдельными файлами в `assets/`: игрок качает их, только
когда комикс показывают, а следующая панель подгружается заранее. В однофайловых сборках
они вшиваются в HTML, как рендеры кораблей.
