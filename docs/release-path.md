# Путь к выпуску

> Порядок шагов от сегодняшнего состояния до игроков в магазинах: решения владельца, первый
> сетевой тест, площадки, юридическая часть, аналитика и маркетинг, у каждого шага —
> ответственный. Юридическая часть уточнена 2026-10-27. Техническая готовность — [`readiness.md`](readiness.md),
> запуск сервера — [`launch-runbook.md`](launch-runbook.md).

Закрытый шаг переписывают на месте (✅, дата, ссылка), а не дописывают рядом. Новый стопор
выхода записывают сюда, с ответственным.

## Где мы

- **Две игры играбельны.** Galactic War — альфа, соло и по сети. Sector Zero — шесть глав,
  архив под Яндекс Игры готов к подаче с 2026-09-24.
- **Публикаций, внешних игроков и продуктовых метрик нет.** Есть только внутренние и
  автоматические прогоны.
- **Для выхода нужны решения владельца и завершение обработки данных в интерфейсе/API.**
  Код под подачу, удаление аккаунта, подпись APK и бэкапы вне машины в основном готов.
  Выбор аналитики до сбора, фиксация принятой версии условий и процедура для
  несовершеннолетних ещё требуют реализации; [сверка](legal/implementation-review.md).

## Шаг 2. Первый сетевой тест Galactic War с внешними людьми

**Ответственные:** владелец зовёт 10–20 человек, разработка готовит сервер и разбор.

- **До теста.** Порядок — PTM-2.2 в [`playtest-telemetry-roadmap.md`](playtest-telemetry-roadmap.md):
  соль и токен в `server.env`, живой приёмник телеметрии, метка `?src=` в ссылке.
  На VPS проверить `ALLOWED_ORIGINS` (сайт Cloudflare и APK `http://localhost`) и решить,
  кто создаёт партии: на 2026-10-18 создание игроками закрыто политикой хоста.
- **До сбора данных тестеров.** Определить оператора, доступный контакт и основания
  обработки; исполнить соответствующие меры из [сверки документов](legal/implementation-review.md).
  Веб-телеметрия сейчас запускается без выбора: текст согласия сам по себе этого
  не исправляет. Статус плейтеста не заменяет основание обработки.
- **Во время.** `/metrics/summary` раз в полчаса.
- **После.** Журналы с хоста, `pnpm run metrics`, `pnpm run analytics`, анкета тестеров.
- **Цель:** первые цифры (дошли ли до конца первого часа, вернулись ли на следующий день) и
  список болей, а не новые механики.

## Шаг 3. Sector Zero на Яндекс Играх

Идёт параллельно шагу 2, как только принято решение 2 из шага 1.

- **Перед подачей:** переснять кадры забега (§2 карточки), вписать номер счётчика Метрики
  (YAG-5.1 🔶), пройти чек-лист §3 карточки в черновике.
- **После модерации:** покупки и серверный кошелёк (YAG-4.x) — когда появятся первые игроки.

## Шаг 4. Android и RuStore

- **Сетевой клиент:** release-воркфлоу, удаление аккаунта, проверка подписи и манифеста,
  учение выпуска 2026-10-18 готовы. Нужны решения 1 и 3, финальный `appId`, закрытый ключ
  подписи и аккаунт разработчика. Порядок — [`security/rustore-preparation.md`](security/rustore-preparation.md),
  карта требований — [`rustore-release-roadmap.md`](rustore-release-roadmap.md).
- **Sector Zero как отдельное приложение** — [`mobile/rustore-sector-zero-release-roadmap.md`](../mobile/rustore-sector-zero-release-roadmap.md).

## Шаг 5. Маркетинг-минимум под первый выход

**Ответственные:** владелец (решения, аккаунты площадок и сообщества), разработка (тексты,
скриншоты).

- Страница игры для игроков, а не для разработчиков.
- 4–8 скриншотов и короткое видео. Для Sector Zero скриншоты снимает `pnpm run store:shots`.
- Канал сообщества: Telegram или VK.
- Текст витрины — [`store-description.md`](store-description.md): факты сверены
  2026-10-19, ждёт названия.

## Шаг 6. После первых цифр

Порядок решают данные теста, а не план заранее. Кандидаты:

- продуктовая аналитика: воронка и D1/D7 (M6 ⏳ в [`metrics-roadmap.md`](metrics-roadmap.md));
- push игрокам: триггер дайджеста и подписка в клиенте (ONB-5 🔶, CP7.1/CP7.3 ⏳);
- баланс основной игры (BAL-10 🔶);
- эксплуатация: прогон 24–72 ч, алерты, приёмка HTTPS-7.1.

игроков.
