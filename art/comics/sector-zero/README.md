# Averion: Sector Zero — страницы комикса

Три утверждённые страницы на русском языке, в порядке сюжета. Сохранены исходные PNG без изменения изображения и качества.

| № | Страница | Сцена |
| --- | --- | --- |
| 01 | [Протокол допуска](01-protocol-admission-ru.png) | Учебная симуляция. |
| 02 | [Инструктаж](02-sector-zero-briefing-ru.png) | Назначение офицера в Сектор Зеро перед первой экспедицией. |
| 03 | [Спасти учёного](03-scientist-rescue-ru.png) | Страница после выполнения миссии спасения учёного: приказ следовать за офицером, доклад по дороге к кораблям и отлёт. |

На учебной странице убрана надпись «Принять». Страница спасения содержит пять кадров: после реплики «Доложите обстановку» сразу показан отлёт кораблей. Кадра «Научный корабль на связи» нет.

Это отдельная папка исходных страниц. Подключение изображений к игровому проигрывателю и событиям миссий в этот PR не входит. Существующий формат игровых панелей описан в [руководстве по комиксам](../../../prototype/art/comics/README.md).
