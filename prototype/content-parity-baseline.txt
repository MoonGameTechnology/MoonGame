# Базовый список расхождений двух каталогов контента (CONV-11 завёл, CONV-12 сводит).
#
# Контент был заведён ДВАЖДЫ: `prototype/src/prototypeData.ts` и `data/*.json`. Ядро
# контента не знает — оно принимает `GameData` как данные, — поэтому один движок спокойно
# гонял два разных набора, и ничто не мешало завести юнит в одном каталоге и забыть про
# другой. Так они и разъехались: совпали только идентификаторы. С CONV-12b каталог один
# (см. ниже), и файл дорабатывает свой последний шаг в роли эталона.
#
# Этот файл НЕ разрешает расхождения — он их ПЕРЕСЧИТЫВАЕТ. Каждая строка = один
# накопленный долг, который сведёт CONV-12; сторож (`contentParity.test.ts`) краснеет
# на ЛЮБОМ отличии от этого списка:
#   · появилась новая строка  → дрейф вырос, это чинят, а не дописывают сюда;
#   · пропала строка          → долг закрыт, убери её тем же PR (конвенция
#                               `.trivyignore`: запись живёт, пока живёт обоснование).
#
# Формат: `<раздел>/<ключ> only-in-prototype|only-in-canon` — сущность есть лишь в одном
# каталоге; `<раздел>/<ключ> field:<поле>` — сущность общая, поле разошлось. Гранулярность
# полевая намеренно: иначе новое поле у уже разошедшегося юнита спряталось бы за строкой
# про эту сущность.
#
# Снят 2026-08-27 (CONV-11) с `prototypeData.ts` против бандла `data/*.json` версии 0.1.9:
# 274 строки. Дальше сокращался только теми правками, что закрывают ДЕФЕКТ канона, а не
# выбирают сторону в развилке CONV-12:
#   · 2026-09-06 (CONV-15), бандл 0.1.10 — 274 → 261: тринадцать полей, которых в сыром
#     `data/*.json` не было вовсе; дефолт схемы подставлял 0 и молча менял правила.
#   · 2026-09-06 (CONV-17), бандл 0.1.11 — 261 → 210: пятьдесят одно `description`,
#     где канон держал готовую прозу (29 из них — по-русски) вместо ключа локализации,
#     хотя потребители зовут `t(description)`. Ключи уже существовали в обеих локалях.
#   · 2026-09-07 (HC-3 + CONV-17), бандл 0.1.12 — 216 строк: HC-3 принёс три способности
#     героя и три узла дерева, и к ним то же правило применено сразу.
#   · 2026-09-07 (CONV-16), бандл 0.1.12 — 216 → 213: сняты три недостижимых гейта
#     `has_scientist` на ветки, у которых учёного в каталоге нет вовсе.
#   · 2026-09-09 (блок ROS) — 99 → 98: `units/dropship field:faction` закрылось само,
#     попутной правкой обоих каталогов.
#   · 2026-09-08 (CONV-12a), бандл 0.1.17 — 213 → 99: канон принял балансные числа и
#     14 сущностей прототипа. Правило выбора стороны — не вкус, а вопрос «КТО ЧИТАЕТ ЭТО
#     ПОЛЕ в графе модулей, который крутит прототип»: читает — побеждает прототип (его
#     числа мерили девять кирпичей BAL); не читает никто или читает только каноническая
#     машинерия (`pve`, `factionStart`, `visibility`) — остаётся канон, и такая строка
#     закроется сама, когда умрёт второй каталог.
#
# ЧТО ЭТОТ СПИСОК ОЗНАЧАЕТ ПОСЛЕ CONV-12b. Живой каталог теперь ОДИН: прототип, прото-хост
# и оба харнеса замера читают `data/*.json` (через `prototype/src/gameData.ts`). Файл
# `prototypeData.ts` остался ЭТАЛОНОМ и игру больше не питает — он держится ровно до тех
# пор, пока сторож доказывает, что переезд принёс РОВНО эти 98 строк и ничего сверх. Это
# и есть причина, по которой снос вынесен в отдельный шаг C: удалив эталон тем же
# коммитом, доказательство пришлось бы принимать на слово.
# Строк `only-in-prototype` среди них нет ни одной (отдельный сторож-храповик), то есть
# бандл — надмножество того, что играбельный прототип нёс до переезда.
#
# ВАЖНО, и это правка утверждения из HC-3: «новая сущность героя платит ДВЕ строки, и
# починить их нечем, кроме сведения каталогов» — верно только для ПОЛОВИНЫ пары.
#   · `description` чинится и до CONV-12: поле обязано держать КЛЮЧ (его зовут через
#     `t()` — `heroStaff.ts`, `techTree.ts:324`), а у общей сущности ключ у прототипа уже
#     есть и уже заведён в обеих локалях. Так закрыт 51 случай в CONV-17 и 6 из HC-3.
#   · `name` действительно ждёт CONV-12: у ШИПНУТОГО бандла имя английское, а перевод
#     живёт ключом `data.<слаг>` (это держит `i18n.test.ts`), тогда как прототип рисует
#     имена героев и учёных через `t(name)`. Две живые конвенции; CONV-12a выбрал форму
#     БАНДЛА — её держит гейт, — так что правка на стороне прототипа: перевести рендереры
#     на `tData()`. Эти 31 строка закроются в шаге B.
# Поэтому новая сущность героя платит ОДНУ строку (`field:name`), а не две.
#
# Что осталось верным из заметки HC-3 (остальное поправлено абзацем выше — «платит ДВЕ
# строки, чинить нечем» было ошибкой, и шесть из двенадцати её строк уже закрыты): ни одна
# из них не про расхождение МЕХАНИКИ. `type`/`cooldownHours`/`range`/`params`/`hook`/
# `scope`/`branch`/`requires`/`cost`/`grants` у всех шести новых сущностей совпадают
# побайтно — сторож это проверил, и именно поэтому остаток дрейфа чисто текстовый.
