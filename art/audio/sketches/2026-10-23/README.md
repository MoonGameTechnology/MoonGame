## Музыка

Центр ля–ми продолжает интервалы текущих `send` и `start`. Темп 90 BPM; мягкие
синтезаторные подложки, короткий мотив A–E–B–C, приглушённый верх и тёмное эхо.

| Фрагмент | Назначение |
| --- | --- |
| 0:00–0:32 | Спокойная стратегическая карта |
| 0:32–1:04 | Постепенное нарастание напряжения и пульса |
| 1:04–1:28 | Изменение знакомого мотива при появлении Роя |
| 1:28–1:36 | Возвращение к ля–ми и затухание |

Это единый композиционный демонстратор с окончанием, а не бесшовный игровой цикл.
Длительность оригинального WAV — 96 секунд; пик −2,80 dBFS, RMS −15,93 dBFS.
Показатели относятся к WAV до MP3-кодирования; они не задают громкость в игре.

## Воспроизведение исходников

Все звуки сочинены и синтезированы программно, без внешних записей и сэмплов.
Использованы Python 3, NumPy 2.3.5 и SciPy 1.17.0. Из корня репозитория:

```bash
python art/audio/sketches/2026-10-23/source/compose_music_v2.py
python art/audio/sketches/2026-10-23/source/compose_event_sounds.py
```

Первый скрипт создаёт исходный WAV музыки и метаданные; второй — отдельные WAV,
WAV-подборку и её метаданные. Оба используют фиксированный seed. Крупный WAV музыки
и дублирующий WAV-предпросмотр не хранятся в Git: они восстанавливаются скриптами.

Для повторного экспорта MP3 нужен FFmpeg с `libmp3lame`:

```bash
cd art/audio/sketches/2026-10-23
ffmpeg -i music/void-dominion-beyond-the-signal.wav -c:a libmp3lame -b:a 192k void-dominion-beyond-the-signal.mp3
ffmpeg -i void-dominion-event-sounds.wav -c:a libmp3lame -b:a 192k void-dominion-event-sounds.mp3
```

[SHA256SUMS](SHA256SUMS) фиксирует опубликованные аудиофайлы, исходники и метаданные;
версии энкодера могут изменить байты MP3 при повторном экспорте.

## Перед игровым подключением

После прослушивания нужно согласовать тембры и уровни, подготовить бесшовные
музыкальные слои и переходы, отдельную регулировку музыки, приоритеты уведомлений
и ограничение повторов. События должны опираться только на доступную игроку
информацию: звук не должен раскрывать происходящее под туманом войны.

Текущие правила паузы площадки, пользовательского отключения звука и ленивого
запуска AudioContext нужно сохранить. Эти изменения не входят в данный набор.

Проведена техническая проверка форматов, длительности, клиппинга и границ WAV.
Субъективное прослушивание в игровом клиенте не выполнялось.
