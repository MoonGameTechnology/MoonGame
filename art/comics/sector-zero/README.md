# Averion: Sector Zero — страницы комикса

Пять страниц на русском языке, в порядке сюжета. Сохранены финальные PNG в исходном разрешении без перекодирования.

| № | Страница | Сцена |
| --- | --- | --- |
| 01 | [Протокол допуска](01-protocol-admission-ru.png) | Учебная симуляция. |
| 02 | [Инструктаж](02-sector-zero-briefing-ru.png) | Назначение офицера в Сектор Зеро перед первой экспедицией. |
| 03 | [Спасти учёного](03-scientist-rescue-ru.png) | Страница после выполнения миссии спасения учёного: приказ следовать за офицером, доклад по дороге к кораблям и отлёт. |
| 04 | [Глава IV: вступление](04-chapter-four-intro-ru.png) | «Архив без ответа»: учёный сообщает о молчании персонала резервного архива и записях на изолированном накопителе. Офицер отдаёт приказ идти к точке встречи с отрядом поддержки. Страница для начала главы, до контакта с союзником. |
| 05 | [Глава IV: точка встречи](05-chapter-four-allied-contact-ru.png) | Встреча с прикомандированным офицером, рукопожатие, установление связи и обмен разведданными. Страница после выполнения `chain.contact`. Утверждённая версия с исправленными первым и последним кадрами. |

На учебной странице убрана надпись «Принять». Страница спасения содержит пять кадров: после реплики «Доложите обстановку» сразу показан отлёт кораблей. Кадра «Научный корабль на связи» нет.

На страницах 04–05 исправлена согласованность погон и нашивок между кадрами. Эталон формы для дальнейших страниц:

- Главный офицер носит чёрную форму без дополнительного нагрудного значка.
- На каждом погоне — ровно три одинаковые параллельные серебристые прямоугольные планки с равными промежутками.
- На верхней части каждого рукава — тёмная нашивка с тонким серебристым контуром перевёрнутого треугольника и одним вложенным V-образным шевроном; без точек внутри.
- У прикомандированного офицера сохраняются синяя отделка формы и погон, три серебристые планки и та же эмблема подразделения.
- Ракурс, складки ткани и освещение меняют видимость деталей, но не их количество, рисунок или место на форме.

Это отдельная папка исходных страниц. Подключение изображений к игровому проигрывателю и событиям миссий в этот PR не входит. Существующий формат игровых панелей описан в [руководстве по комиксам](../../../prototype/art/comics/README.md).
