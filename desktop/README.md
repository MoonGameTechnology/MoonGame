# Sector Zero — ПК-версия (Electron)

Пробная обёртка: запускает **архив площадки** (`prototype/dist/yandex/` — Sector Zero, один
язык файлом, ассеты рядом) в окне Electron, чтобы посмотреть, как игра ведёт себя на ПК.
Отдельный проект (не в pnpm workspace), как `mobile/`; ставится через `npm`.

## Запуск

```bash
cd desktop
npm install
npx electron --version || node node_modules/electron/install.js   # если npm пропустил postinstall
npm start          # собирает прототип, кладёт архив в www/ и открывает окно
```

Сборка папки с исполняемым файлом (без инсталлятора и без подписи):

```bash
npm run pack:win     # out/Sector Zero-win32-x64/Sector Zero.exe
npm run pack:linux   # out/Sector Zero-linux-x64/
```

## Как устроено

- `main.mjs` — главный процесс. Страница грузится со своей схемы `app://game/`, а не с
  `file://`: архив скачивает файл языка (`fetch`) и запускает поток симуляции, а Chromium на
  `file://` запрещает и то и другое. Схема даёт игре обычный origin, поэтому сохранения в
  `localStorage` живут между запусками (в профиле пользователя Electron).
- Странице не дан Node: `sandbox`, `contextIsolation`, без preload. Внешние ссылки открываются
  в системном браузере, переходы с `app://game/` запрещены, запросы разрешений отклоняются.
  Вторая копия приложения не стартует — две копии делили бы одно сохранение.
- `routes.mjs` — чистая маршрутизация запросов (тест `routes.test.mjs` в общем гейте):
  только файлы внутри `www/`, всё остальное 404.

## Яндекс SDK

Тег лоадера `<script async src="/sdk.js" onload="initSDK()">` остаётся в архиве как есть —
его требует модерация площадки. На ПК SDK нет, и обёртка отвечает на `/sdk.js` лоадером-
заглушкой: `window.YaGames.init()` возвращает `null`, и `prototype/src/platform/host.ts`
молча выбирает веб-адаптер (реклама и покупки `unavailable`, в отчёт об ошибках ничего не
уходит). Код игры и разметка архива не меняются.

Почему не 404 и не пустой файл: `bootstrap.ts` ждёт либо `window.YaGames`, либо событие
`ya-sdk-ready`. Локальный `/sdk.js` загружается раньше бандла игры, событие уходит, пока
его никто не слушает, и без `YaGames` игра каждый запуск отсиживала потолок ожидания SDK
(3 с). Замер холодного запуска до показа меню: 3,6 с без `YaGames`, 0,9 с с заглушкой.
